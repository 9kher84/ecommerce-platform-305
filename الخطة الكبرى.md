# Mission

The purpose of this investigation is not to fix random bugs.

The purpose is to completely understand the production system, identify every verified root cause, eliminate assumptions, and produce evidence-based conclusions.

Every investigation must support this mission.

Whenever uncertainty exists, the investigator must explicitly state:

> Insufficient evidence.

Evidence always overrides assumptions.

---

# Investigation Rules

These rules are mandatory.

1. Never invent production data.
2. Never invent users.
3. Never invent log files.
4. Never assume Render configuration.
5. Never assume database contents.
6. Every conclusion must reference collected evidence.
7. If evidence is missing, stop and request evidence.
8. Every completed investigation must update this document.
9. Never change investigation direction without checking this Master Plan.
10. Whenever asked "Where are we?", first consult this document.
